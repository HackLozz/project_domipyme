Este directorio almacena los recursos estáticos de la plataforma (imágenes, íconos, logos) servidos por Vite desde `public/`.

Estructura sugerida:
- logo.svg: logo principal de la plataforma
- logos/: variantes del logo (oscuro/claro)
- illustrations/: imágenes decorativas de páginas
- products/: imágenes por defecto o genéricas

Nota: Coloca aquí los assets públicos. Para imágenes importadas en componentes via bundling, usa `src/assets/`.
